01 / What it does

Three source files in. A traceable exception worklist out.

01 / Ingest

Load invoice lines, purchase-order lines, and goods receipts from CSV exports. No account or upload endpoint is required for this evaluation.

02 / Reconcile

Apply explicit checks for duplicate identifiers, missing references, supplier differences, price and quantity mismatches, and receipt gaps.

03 / Review

Search findings, inspect the evidence, and export a CSV for a human to resolve. A clean result means only that the current rules did not flag a line.

02 / Paid evaluation

Test it against a known answer—not a sales demo.

The proposed engagement is a fixed-scope evaluation using synthetic or approved anonymized records and a human-reviewed reference set. We agree on the inputs and rules first, then document confirmed findings, false positives, missed exceptions, and review effort.

Scope, fee, timeline, and success criteria are agreed before work begins. If the evidence does not support repeat use, we should not pretend it does.

WHAT THE EVALUATION SHOULD PROVE
  • Which known exceptions were detected or missed
  • Which findings were confirmed as true exceptions
  • How much review time the workflow requires
  • Whether the same input produces repeatable output
